# RE:SPEAR 게임 기획서

- 게임 제목: RE:SPEAR
- 작성자: 김민준
- 장르: 2D 횡스크롤 액션
- 개발 환경: C#, glc2d, Visual Studio 2022
- 구현 범위: 일반 맵 2개, 보스 맵 1개

## 게임 개요

플레이어가 창 한 자루를 사용해 적을 상대하는 2D 횡스크롤 액션 게임이다. 창은 마우스로 조준해 충전한 뒤 투척하며, 투척한 창은 자동으로 돌아오지 않으므로 직접 접근해 회수해야 한다. 충전 시간이 길수록 창의 피해량과 최대 투척 거리가 증가하지만, 멀리 떨어진 창을 회수하기 위해 위험을 감수해야 할 수 있다.

- **핵심 재미:** 창의 투척 위력과 회수 위험을 고려하며 적과의 거리를 조절하는 전투.
- **핵심 규칙:** 창을 던진 뒤에는 회수할 때까지 다시 공격할 수 없으며, 창을 소지한 상태에서는 밀쳐내기로 거리를 확보할 수 있다. 창이 없는 상태에서는 이동과 대시 등을 활용해 창을 회수해야 한다.

## 게임 목표 및 진행

일반 맵 1 → 일반 맵 2 → 보스 맵 순서로 진행한다. 각 맵의 적을 모두 처치하면 다음 맵으로 이동하며, 마지막 보스를 처치하면 게임을 클리어한다.

플레이어의 체력이 0이 되면 게임 오버가 되고, 다시 도전할 때는 일반 맵 1부터 시작한다.

### 맵 구성

- **일반 맵 1:** 기본적인 창 투척과 회수, 밀쳐내기 및 대시를 활용하는 전투 구간.
- **일반 맵 2:** 높은 체력과 방어력을 가진 탱커형 적이 추가되며, 적의 배치와 공격 패턴을 고려해 창을 반복적으로 투척하고 회수해야 하는 전투 구간.
- **보스 맵:** 앞선 맵에서 사용한 전투 시스템을 종합적으로 활용하여 보스를 상대하는 최종 전투 구간.

맵별 적의 구체적인 수와 배치, 지형은 제작 과정에서 결정한다.

### 게임 배경 및 지형

게임은 2D 횡스크롤 방식으로 진행하며, 각 맵은 배경 이미지와 플레이어가 이동할 수 있는 지형으로 구성한다.

- 배경 이미지와 실제 충돌 판정이 적용되는 바닥, 벽, 발판을 구분하여 제작한다.
- 일반 맵 2개와 보스 맵은 서로 다른 적 배치와 지형 구조를 가지도록 구성한다.
- 플레이어와 적의 위치 및 공격 범위를 쉽게 파악할 수 있도록 배경과 캐릭터가 구분되게 구성한다.
- 모든 투척 상황에서 창을 회수할 수 있도록 지형을 설계한다.

## 기본 조작

| 입력 | 동작 |
| --- | --- |
| A / D | 좌우 이동 |
| Space | 점프 |
| 마우스 이동 | 창 투척 방향 조준 |
| 마우스 좌클릭 누르기 | 창 투척 차징 |
| 마우스 좌클릭 떼기 | 차징한 창 투척 |
| 마우스 우클릭 | 창 소지 시 가까운 적 밀쳐내기 |
| Shift | 짧은 대시 |
| E | 가까이 떨어진 창 회수 |

※ 이동·점프·대시·회수의 구체적인 키 배치는 개발 과정에서 조정할 수 있다.

## 핵심 시스템

### 1. 창 차징 및 투척

- 창을 소지한 상태에서 마우스 좌클릭을 누르고 있으면 차징한다.
- 좌클릭을 떼면 마우스 방향으로 창을 투척한다.
- 차징 시간이 길수록 피해량과 최대 투척 거리가 증가한다.
- 차징 중에는 이동할 수 있지만 이동 속도가 감소하며, 점프·대시·밀쳐내기는 사용할 수 없다.
- 별도의 기본 공격은 없으며, 창 투척이 주된 피해 수단이다.
- 창은 적을 관통하지 않는다. 적에게 명중하면 피해를 준 뒤 바닥으로 떨어진다.
- 적에게 명중하지 않으면 차징에 따라 결정된 최대 투척 거리까지 날아간 뒤 바닥으로 떨어진다.

### 2. 창 회수

- 투척한 창은 자동으로 돌아오지 않는다.
- 플레이어가 떨어진 창 근처로 직접 이동해 회수해야 한다.
- 창을 회수하기 전에는 다시 창을 투척할 수 없다.
- 창이 없는 상태에서는 이동, 점프, 대시를 사용할 수 있지만 밀쳐내기는 사용할 수 없다.
- 창을 회수하는 과정에서 적의 공격과 위치를 고려해야 한다.
- 모든 투척 상황에서 창을 회수할 수 있도록 맵과 지형을 설계한다.

### 3. 밀쳐내기

- 창을 소지한 상태에서 마우스 우클릭으로 플레이어 가까이에 있는 적을 밀쳐낸다.
- 창대를 양손으로 잡고 가로로 들어, 창대로 적을 밀어내는 동작이다.
- 피해량은 없으며, 적을 멀지 않은 거리만큼 밀어낸다.
- 창을 투척하여 소지하지 않은 상태에서는 사용할 수 없다.
- 차징 중에도 사용할 수 없다.
- 재사용 대기시간이 존재한다.
- 적과의 거리를 확보해 창을 차징하거나 투척할 기회를 만드는 보조 행동이다.

### 4. 대시

- 플레이어가 짧은 거리를 순간적으로 빠르게 이동한다.
- 선딜레이와 후딜레이가 없으며, 무적 효과도 없다.
- 연속 사용으로 먼 거리를 빠르게 벌릴 수 없도록 사용을 제한한다.
- 창 소지 여부와 관계없이 사용할 수 있지만 차징 중에는 사용할 수 없다.
- 대시는 순간적인 공격 회피에, 밀쳐내기는 적과의 거리 확보에 각각 사용한다.

## 적 종류

| 종류 | 특징 | 플레이어에게 요구하는 판단 |
| --- | --- | --- |
| 근접형 | 검을 사용하며 플레이어에게 접근해 근접 공격 | 차징 시간과 근접 거리 관리 |
| 원거리형 | 활을 사용하며 떨어진 위치에서 원거리 공격 | 화살 회피와 창 회수 경로 판단 |
| 탱커형 | 전신 갑옷과 철퇴를 사용하며 높은 체력과 방어력으로 쉽게 처치되지 않음 | 반복적인 창 투척과 회수, 적과의 거리 관리 |
| 보스 | 최종 맵에서 등장하는 강한 적 | 창 투척·회수·밀쳐내기·대시의 종합 활용 |

탱커형 적은 공격받는 방향과 관계없이 높은 체력과 방어력을 가진다. 보스의 구체적인 공격 패턴은 추후 설계한다.

### 적의 공격 예고

- 적이 공격하기 전에 공격 범위를 화면에 표시한다.
- 플레이어는 표시된 공격 범위를 확인하고 이동이나 대시로 회피할 수 있다.
- 공격 범위 표시는 근접형, 원거리형, 탱커형, 보스의 공격에 적용한다.
- 공격 범위와 예고 시간은 적의 종류 및 공격 패턴에 따라 다르게 설정한다.

## 기본 전투 흐름

적의 위치와 공격을 확인 → 이동 또는 밀쳐내기로 거리 확보 → 창 차징 및 투척 → 이동과 대시로 적의 공격을 회피하며 창에 접근 → 창 회수 → 다시 투척

차징을 오래 하면 강한 공격이 가능하지만, 창이 멀리 떨어질 수 있어 회수 부담이 커진다. 반대로 짧게 차징하면 공격 위력은 낮지만 빠르게 투척할 수 있다.

창을 소지한 상태에서는 밀쳐내기로 적과의 거리를 확보할 수 있지만, 창을 던진 뒤에는 밀쳐내기를 사용할 수 없다. 따라서 플레이어는 창을 던질 시점과 위치뿐만 아니라, 이후 창을 회수할 경로까지 고려해야 한다.

## 캐릭터 애니메이션

캐릭터의 행동에 맞춰 여러 장의 이미지를 순서대로 출력하는 스프라이트 애니메이션 방식을 사용한다.

### 주인공

- **대기:** 제자리에서 창을 들고 대기하는 동작.
- **이동:** 좌우로 달리는 동작.
- **점프:** 지면에서 뛰어오르는 동작.
- **낙하:** 공중에서 떨어지는 동작.
- **대시:** 짧은 거리를 빠르게 이동하는 동작.
- **차징:** 창을 한 손으로 들어 어깨 위로 당긴 뒤 투척을 준비하는 동작.
- **투척:** 차징의 마지막 자세에서 이어져 창을 앞으로 던지는 동작.
- **밀쳐내기:** 창대를 양손으로 잡고 가로로 들어 적을 밀어내는 동작.
- **피격:** 적의 공격에 맞았을 때의 반응.
- **사망:** 체력이 0이 되었을 때 쓰러지는 동작.

창을 던진 뒤에는 창을 소지하지 않은 상태에 맞는 캐릭터 이미지를 사용한다.

### 일반 적

| 종류 | 주요 애니메이션 |
| --- | --- |
| 근접형 | 대기, 이동, 검 공격, 사망 |
| 원거리형 | 대기, 이동, 활시위 당기기 및 발사, 사망 |
| 탱커형 | 대기, 이동, 철퇴 공격, 사망 |

### 보스

보스는 대기, 이동, 공격, 피격, 사망 등의 애니메이션을 사용하며, 공격 패턴에 따른 구체적인 동작은 추후 설계한다.

## 사운드 구성

### 배경음악(BGM)

- 시작 화면, 일반 전투, 보스 전투의 상황에 맞는 배경음악을 사용한다.
- 게임 플레이 중 배경음악이 반복 재생되도록 구성한다.
- 맵이나 게임 상태가 변경되면 상황에 맞는 배경음악으로 전환한다.

### 효과음(SFX)

- 창 차징 및 투척
- 창 명중 및 회수
- 밀쳐내기
- 플레이어 대시
- 적 공격 및 피격
- 적 사망
- 게임 클리어 및 게임 오버

효과음은 플레이어의 행동과 전투 상황을 명확하게 전달할 수 있도록 사용한다.

## 게임 화면 구성

### 시작 화면

게임 제목과 기본 조작 방법을 안내하고 게임 시작 및 종료 기능을 제공한다. 시작 화면에 맞는 배경 이미지와 음악을 사용한다.

### 플레이 화면

플레이어, 창, 적, 배경 및 지형을 표시한다.

플레이어의 체력, 현재 맵, 창 소지 여부와 차징 상태, 밀쳐내기 및 대시의 사용 가능 상태를 확인할 수 있도록 구성한다.

적이 공격하기 전에는 공격 범위를 표시하여 플레이어가 공격을 예측하고 회피할 수 있도록 한다.

캐릭터의 행동에 따른 애니메이션을 재생하고, 게임 플레이 중 배경음악과 전투 효과음을 출력한다.

### 결과 화면

보스를 처치하면 클리어 화면을, 플레이어의 체력이 0이 되면 게임 오버 화면을 표시한다. 다시 시작하면 일반 맵 1부터 진행한다.

## 리소스 구성

게임 제작에 사용할 이미지와 사운드 리소스를 용도별로 구분하여 관리한다.

| 분류 | 구성 |
| --- | --- |
| 주인공 이미지 | 대기, 이동, 점프, 낙하, 대시, 차징, 투척, 밀쳐내기, 피격, 사망 |
| 적 이미지 | 근접형, 원거리형, 탱커형, 보스의 행동별 이미지 |
| 무기 이미지 | 플레이어의 창, 원거리형 적의 화살 등 |
| 배경 이미지 | 일반 맵 1, 일반 맵 2, 보스 맵 |
| 지형 이미지 | 바닥, 벽, 발판 등 |
| UI 이미지 | 체력, 차징 게이지, 밀쳐내기 및 대시 재사용 대기시간 표시 |
| 전투 이펙트 | 창 명중, 피격, 적 공격 범위 예고 등 |
| 배경음악 | 시작 화면, 일반 전투, 보스 전투 |
| 효과음 | 이동 및 전투 행동, 피격, 사망, 클리어 등 |

캐릭터 이미지는 동작별 스프라이트 시트로 관리하며, 게임에서 사용할 수 있도록 프레임을 구분한다. 캐릭터와 무기 등은 배경을 제거한 이미지를 사용하고, 배경 및 지형 이미지와 분리하여 출력한다.

리소스 파일은 이미지와 오디오를 구분하고, 캐릭터·무기·배경·UI 등 세부 용도에 따라 폴더를 분류하여 관리한다.

## 구현 범위 및 개발 방향

### 구현 범위

- 일반 맵 2개와 보스 맵 1개 제작
- 플레이어 이동, 점프, 대시, 밀쳐내기 구현
- 마우스 조준, 창 차징, 투척, 충돌, 낙하, 직접 회수 구현

- 적의 행동 및 공격 범위 예고 시스템 구현
- 적 전멸에 따른 맵 전환, 체력 및 게임 오버, 클리어 처리
- 캐릭터 행동별 스프라이트 애니메이션 구현
- 배경 및 지형 이미지 렌더링
- 배경음악 및 전투 효과음 출력
- 체력, 차징 상태, 재사용 대기시간 등 기본 UI 구현

### 개발 단계

| 단계 | 구현 목표 |
| --- | --- |
| 기본 구조 | 게임 실행 환경 구성, 기본 클래스 작성, 리소스 로드 구조 구현 |
| 기본 플레이 | 배경 및 캐릭터 렌더링, 키보드 이동, 배경음악 출력 |
